College Mini-Project Walkthrough Guide

1. Project Working Principle

This automated parking system utilizes an Arduino Uno microcontroller as the central brain. It constantly monitors infrared (IR) proximity sensors located at the entrance gate and inside each individual parking slot.

2. Vehicle Entry & Barrier Automation

When a vehicle arrives at the entrance, the Entrance IR Sensor (Pin D2) beam is interrupted. The Arduino checks the available slot count:

  • If Available > 0: Arduino sends PWM signal to Servo Motor (Pin D9) to rotate the barrier gate open (90°), updates the 16x2 LCD screen, and guides the car into the first vacant slot.
  • If Available == 0: Arduino triggers the Piezo Alert Buzzer (Pin D10), displays "PARKING FULL" on LCD, and keeps the barrier gate CLOSED.

3. Real-time Slot Monitoring & LEDs

Each slot contains an independent IR sensor (Pins D3, D4, D5) and status LEDs (Green = Vacant, Red = Occupied). When a car parks over a sensor, the corresponding LED instantly turns RED, and the 16x2 LCD display updates the count dynamically.
